# OMNIX — Universal AI & Real-Time Intelligence Platform

OMNIX is a next-generation intelligence, real-time verified news, and AI knowledge synthesis platform.

## Features

1. **AI Conversation Terminal**: Deep reasoning, factual synthesis, multi-turn conversational core.
2. **Live Web Search**: Grounded real-time web retrieval with source verification.
3. **Verified Live News Hub**: 100% authentic live headlines across 8 categories (Top Stories, India, World, Business, Technology, Science, Sports, Entertainment) with 5-step verification and zero mock placeholders.
4. **OMNIX Briefing**: Editorial AI news briefings summarizing current developments with direct source citations.
5. **Multi-Source Coverage Comparison**: Cross-outlet side-by-side reporting comparison.
6. **Live Voice Interaction**: Interactive microphone, audio waveform visualizer, and speech synthesis.
7. **Live Data Tools**: Real-time market indices (S&P 500, Nasdaq, 10Y Yield, Crude, Gold, Bitcoin) and wholesale commodity benchmarks.
8. **Company Intelligence**: Corporate profiles, strategic initiatives, and live news audits (Apple, NVIDIA, Google, Microsoft, Tesla, TSMC).
9. **People Intelligence**: Leadership and research dossiers on key pioneers.
10. **Places & Geospatial Explorer**: Innovation hubs, regional metrics, and localized coverage.
11. **Science & Research**: Peer-reviewed discoveries across astrophysics, quantum systems, and biotech.
12. **Global Real-Time Trends**: Search velocity indicators and breakout topic analysis.
13. **Knowledge Graph**: Topological network graph visualizer connecting entities, topics, and sources.
14. **Saved & History**: Offline bookmarking with JSON export and chronological inquiry timeline.

## Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Environment Variables
Create a `.env` file based on `.env.example`:
```env
GEMINI_API_KEY="your-gemini-api-key"
```

### 3. Run the Development Server
```bash
npm run dev
```

Visit `http://localhost:3000` in your browser.

### 4. Build for Production
```bash
npm run build
npm start
```
